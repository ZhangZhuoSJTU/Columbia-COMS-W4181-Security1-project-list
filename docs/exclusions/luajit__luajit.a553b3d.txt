#    compilation, type specialization, etc.) assert x86 trace behavior;
#  * -b bytecode tooling needs the jit.* Lua modules installed (only present under
#    the source tree here);
#  * FFI ABI reports arch=arm64 vs the golden's x64;
#  * PRNG seeding is arch-dependent, and APFS is case-insensitive.
