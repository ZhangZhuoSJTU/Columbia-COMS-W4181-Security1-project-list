# cmatrix calls ncurses initscr()/newterm(). These tests all assert cmatrix's
# behavior in a *broken-terminal* environment (no usable TERM): they expect it
# to exit and print Linux ncurses' exact "Error opening terminal: unknown."
# string, or to not enter the render loop. On macOS the inherited/valid TERM has
# real terminfo, so cmatrix renders instead of failing, and where it does fail
# macOS ncurses prints a different message ("cannot initialize terminal type").
