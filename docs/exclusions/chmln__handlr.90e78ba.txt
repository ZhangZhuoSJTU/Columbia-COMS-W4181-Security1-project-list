# handlr is a Linux XDG desktop-integration tool. On macOS three whole families
# of its tests cannot pass, for the gold binary or any re-implementation:
#  * handlr.toml config: handlr locates its TOML config via the `directories`
#    crate, which on macOS is hard-wired to ~/Library/Preferences/rs.handlr and
#    ignores XDG_CONFIG_HOME (only its mimeapps.list, via the `xdg` crate, honors
#    it). Tests that assert the config lands in $XDG_CONFIG_HOME/handlr therefore
#    fail -- including the one that explicitly checks XDG is respected.
#  * .desktop autocomplete: these expect real freedesktop .desktop application
#    entries (python3.10.desktop, ...) that only exist on a Linux desktop.
#  * open/handler invocation: `handlr open` launches the associated .desktop
#    Exec handler, which does not exist on macOS.
