# All of these fail for the gold binary on macOS due to platform differences,
# not the implementation:
#  * errno numbers/text differ (macOS ELOOP=62, ENAMETOOLONG=63 vs Linux 40/36);
#  * ast-grep's embedded HTML/CSS/JS scanning and custom languages load
#    tree-sitter grammars as dynamic libraries -- dlopen/dylib symbol errors and
#    load behavior differ from Linux .so, so those scans and their error goldens
#    diverge;
#  * the interactive-edit tests drive $EDITOR through a pexpect pty; a real editor
#    hangs headless on macOS and a no-op editor makes pexpect hit EOF, so the
#    interaction cannot be reproduced;
#  * APFS is case-insensitive, so "case-sensitive rule name" collisions error;
#  * macOS canonicalizes temp paths under /private, and lists directory entries
#    in a different order, so path-bearing error goldens and rule-summary ordering
#    do not match; and one test creates a non-UTF-8 filename APFS rejects.
